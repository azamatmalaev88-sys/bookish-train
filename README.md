# bookish-train
Many Kerbal Space Program players can't or don't know how to download mods like those from bloggers like BOGUE or Matt Lowne. The build includes moduelmanager, EnvironmentalVisualEnhancements 3D Clouds (community rework), parallax , scatterer, RESTOCK, deffered, waterfall, firefly, and Z-THEME.  I hope this helps someone.
